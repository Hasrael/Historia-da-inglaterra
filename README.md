# Inglaterra — Um Museu no Tempo

Site estático educativo em português brasileiro, responsivo para computador, tablet e celular.

## Arquivos
- `index.html`: estrutura e conteúdo.
- `styles.css`: identidade visual, layout responsivo e componentes.
- `script.js`: linha do tempo, filtros, janelas de detalhes, curiosidades e quiz.

## Como abrir
Abra `index.html` em um navegador moderno. Para testar como servidor local, dentro desta pasta execute:
`python -m http.server 8000`
e acesse `http://localhost:8000`.

## Como publicar gratuitamente no GitHub Pages
1. Crie uma conta em https://github.com/ (se ainda não tiver).
2. Crie um repositório público chamado `historia-da-inglaterra`.
3. Envie os três arquivos (`index.html`, `styles.css`, `script.js`) para a raiz do repositório.
4. Abra Settings → Pages.
5. Em Build and deployment, escolha Deploy from a branch; selecione `main` e `/ (root)` e salve.
6. Aguarde a publicação. O endereço será parecido com `https://SEU-USUARIO.github.io/historia-da-inglaterra/`.

## Observações
- As imagens de capa e dos cartões são carregadas de URLs externas do Unsplash; por isso, exigem internet e podem ser substituídas por imagens próprias/licenciadas.
- As fontes tipográficas são carregadas do Google Fonts; se estiver offline, o site usa fontes alternativas.
- O marco de 2026 é um encerramento editorial do recorte, não a afirmação de um acontecimento histórico específico.
- Revise e amplie as entradas com bibliografia antes de usar como material acadêmico formal. Datas pré-históricas são aproximadas.
